# Personal media

- Add your 6–10 photos as files in this folder if you prefer local images, then point to them from `src/content/config.ts` (for example, `/media/us-at-the-beach.jpg`).
- Add your collage video here as `collage-video.mp4`, or use another filename and update `collageVideoPath` in `src/content/config.ts`.
- The page accepts common browser formats such as `.jpg`, `.png`, `.webp`, `.mp4`, and `.webm`.
